# Лицензии и происхождение

Савеми Бокс — независимый клиент на libbox sing-box, не официальный продукт SagerNet и не связан с его авторами. Интерфейс и адаптер написаны отдельно; архитектура запуска сверена с SFA. Репозиторий SFA целиком не копировался.

Ядро: https://github.com/SagerNet/sing-box, v1.14.4, commit c005f35300ce76427dc285481ec5695f5b179cd2.

Новый код этого проекта распространяется по GPL-3.0-or-later без гарантий. Полный текст: https://www.gnu.org/licenses/gpl-3.0.txt. При распространении APK предоставляйте соответствующий исходный код, включая закреплённое ядро и сценарий сборки, и уведомления зависимостей. Сборочный сценарий получает исходники ядра в .upstream.

Каталог reference содержит копии публичных исходников исключительно для сверки API. BoxService.kt и VPNService.kt взяты из SFA dev при реализации; приложение не компилирует эти файлы. Остальные файлы закреплены на sing-box v1.14.4.
